OVERVIEW
================================================================

JK3DA KeyFlow displays keyboard and mouse inputs directly
inside the Blender viewport.

Designed for:
  - Tutorial creators
  - Streamers
  - Educators
  - Workflow demonstrations
  - Live presentations

The add-on helps viewers clearly understand actions,
shortcuts, and transform operations during recording
or streaming.

================================================================
FEATURES
================================================================

Input Display
-------------
- Readable action names:
    "Extrude (E)"
    "Inset (I)"
    "Grab (G)"

- Repeat detection:
    "Extrude (E) x3"

- Modifier support:
    Shift + X
    Ctrl + Z
    Alt + S

Mouse Support
-------------
- Left / Right / Middle mouse buttons
- Mouse wheel up/down
- Navigation interaction visibility

Transform Tracking
------------------
- Displays transform workflows:
    "Grab [Z]: 10"

Animations
----------
- Smooth fade-in / fade-out
- Adjustable display duration:
    0.3s — 120s

Editor Support
--------------
Per-editor enable/disable toggles for:
  - 3D Viewport
  - UV/Image Editor
  - Shader / Geometry Node Editor
  - Video Sequence Editor
  - Dope Sheet / Animation Editors

Customization
--------------
- 9 snap positions per editor
- Adjustable:
    - colors
    - opacity
    - font size
    - padding
    - corner radius

Shortcut
--------
Default toggle:
  Shift + Alt + K

================================================================
INSTALLATION
================================================================

1. Open Blender
2. Go to:
     Edit → Preferences → Add-ons
3. Click:
     Install...
4. Select:
     jk3da_keyflow.zip
5. Enable:
     "JK3DA KeyFlow"
6. Open the N-Panel:
     JK3DA KeyFlow tab

================================================================
REQUIREMENTS
================================================================

- Blender 4.0 or newer
