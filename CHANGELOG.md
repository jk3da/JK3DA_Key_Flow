# Changelog — JK3DA KeyFlow

All notable changes are documented here.  
Versioning follows [Semantic Versioning](https://semver.org/).

---

## [1.0.0] — 2026-05-10

First public release of the modular version.

### Added
- Viewport overlay for keyboard and mouse inputs
- GPU-based rounded rectangle badge rendering with fade animation
- Transform state tracking: Grab / Scale / Rotate with axis constraints and numeric input
- Multi-area support: 3D View, UV/Image Editor, Node Editor, Sequence Editor, Dope Sheet
- 9 snap positions per editor area (top/center/bottom × left/center/right)
- Per-area enable/disable toggles
- Key repetition counter (×N display)
- Preferences: text color, background color, opacity, font size, corner radius, fade time, max keys, margin
- Default hotkey: `Shift + Alt + K`
- Sidebar panel in 3D View and UV Editor
