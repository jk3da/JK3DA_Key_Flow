WHAT IT DOES
------------
JK3DA KeyFlow displays your keyboard and mouse inputs directly
in the Blender viewport. Designed for tutorial creators,
streamers, and anyone who wants to show their workflow clearly
on screen.

FEATURES
--------
- Key display          Readable names: "Extrude (E)", "Inset (I)", "Grab (G)"
- Repeat count         Same key multiple times shows "Extrude (E) x3"
- Modifier prefix      Shift + X, Ctrl + Z etc.
- Mouse buttons        LMB, RMB, MMB, Scroll up/down
- Transform display    G to Z to input shows "Grab [Z]: 10"
- Fade animation       Keys appear and fade out smoothly (0.3-120s)
- Per-editor toggles   Enable/disable for each editor separately:
                       3D Viewport, UV/Image Editor, Node Editor, VSE, Dope Sheet
- Position per editor  9 snap positions per editor
- Appearance           Colors, opacity, font size, corner radius adjustable
- Shortcut             Shift+Alt+K to toggle on/off

INSTALLATION
------------
1. Open Blender
2. Edit > Preferences > Add-ons > Install
3. Select jk3da_keyflow.zip
4. Enable "JK3DA KeyFlow" via checkbox
5. Panel: N-Panel > Tab "JK3DA KeyFlow"

REQUIREMENTS
------------
Blender 4.0 or higher
